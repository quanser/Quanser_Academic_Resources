# QCar Ground Station: Web-Based Fleet Monitoring and Control for Multi-Vehicle QCar

## Overview

`QCar Ground Station` is a **web-based operator interface** for monitoring and controlling a **fleet of Quanser QCars** in real time. The frontend is built as a browser dashboard for fleet supervision, while a companion **Python WebSocket bridge** connects it to the vehicle-side software. Together, they provide a practical control layer for starting and stopping missions, deploying paths, monitoring telemetry, configuring platoons, switching controllers and observers, and running V2V-related experiments from one place instead of multiple terminals. It is an integrated workflow for **multi-vehicle QCar experiments, demos, and fleet operations**.

---

## How the Quanser Community Can Use This

- A ready-to-use **Ground Station dashboard** for multi-QCar experiments and demos.
- A practical interface for **fleet monitoring, mission control, and emergency stop** from one screen.
- A useful tool for **platooning and V2V experiments**, including controller and observer switching.
- A cleaner way to supervise experiments with **live telemetry, map visualization, and logs**.
- A good example of combining a **web frontend + Python bridge + QCar backend** into one operator workflow.

---

## Experimental Setup

- **Target platform:** QCar 2
- **Frontend:** React + TypeScript + Vite web app
- **Backend bridge:** Python WebSocket bridge
- **Companion repo:** `QCar2_Cran`
