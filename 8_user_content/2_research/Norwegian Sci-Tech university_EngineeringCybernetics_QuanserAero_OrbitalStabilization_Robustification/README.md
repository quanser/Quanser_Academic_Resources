# Orbital-Stabilization Control for Quanser Aero


## Overview
This repository provides a complete control workflow for the **Aero 1** helicopter configuration using **orbital-stabilization methods**. It includes controller code, simulations, modeling and model verification materials, observer design, identified coefficients (pitch/thrust/yaw), and **experimental demonstrations**.

---

## How the Quanser Community Can Use This
- Use as an **advanced teaching module** for nonlinear/robust control on Quanser Aero.
- Reuse the **modeling + coupling + observer** workflow as a capstone template for building “research-style” controllers on a real plant.
- Run the provided simulations/experiments as a baseline, then **compare your own controller** against the same setup.
- Extend for research: adjust modeling assumptions, observer design, or robustness tuning and report improvements using the included evaluation structure.

---

## Experimental Setup
- **Platform:** Aero1 (2-DOF dual-rotor, pitch/yaw)
- **Artifacts in repo:** controllers, simulations, modeling/verification, observer design, coefficients, and demo/experimental results
