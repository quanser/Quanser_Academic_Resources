# Nonlinear Adaptive Sliding Mode Control (NASMC) Applied to the Quanser Aero


## Overview
This repository provides **MATLAB/Simulink** models and scripts for implementing and testing a **Nonlinear Adaptive Sliding Mode Control (NASMC)** approach on the **Quanser Aero 2-DOF (pitch–yaw) helicopter**. It focuses on translating a previously theoretical NASMC method into a **practical, hardware-realizable control workflow**, emphasizing robustness to **parameter uncertainty**.

---

## How the Quanser Community Can Use This

* Run the **NASMC** Simulink model as an advanced Aero control example.
* Teach **adaptive + sliding-mode** control under **uncertainty**.
* Compare NASMC with baseline controllers (e.g., **PID/LQ**) on pitch–yaw.
* Test robustness by varying parameters and checking tracking/stability.
* Extend to hardware (add Quanser I/O), then share logs and comparisons.

---

## Experimental Setup
- **Platform:** Quanser Aero (2-DOF coupled pitch–yaw)
- **Implementation:** MATLAB + Simulink
