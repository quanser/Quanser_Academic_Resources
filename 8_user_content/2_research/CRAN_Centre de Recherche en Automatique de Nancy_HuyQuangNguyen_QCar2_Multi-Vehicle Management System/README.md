# QCar 2 Multi-Vehicle Management System (QCar2_Cran)

## Overview
QCar2_Cran is a modular multi-vehicle autonomy stack for **Quanser QCar 2** that brings the full fleet workflow into one system: each vehicle runs its own onboard loop for **state estimation, control, state-machine logic, V2V communication, safety checks, and logging**, while a separate **Ground Station App** provides monitoring and command control across the fleet. Designed to support both **real QCar hardware** and **QLabs simulation**, the stack is valuable because it goes beyond a single-vehicle demo and provides a practical foundation for **path following, platooning, fleet coordination, and multi-agent experimentation**.

## How the Quanser Community Can Use This
- **Start faster with a multi-QCar baseline**  
  Use it as a ready-made foundation for running multiple **QCar 2** vehicles under one connected architecture.

- **Test new ideas without rebuilding the stack**  
  Its modular design makes it easier to compare different **controllers, observers, and coordination strategies**.

- **Support teaching and demos**  
  It is a useful platform for showing **fleet behavior, V2V communication, and centralized supervision** in a more complete way.

- **Move from simulation to hardware**  
  The shared structure across **QLabs** and **real QCar hardware** helps reduce friction between development and deployment.

- **Run experiments more easily**  
  Built-in **logging and analysis** make it easier to capture results and improve new workflows over time.
