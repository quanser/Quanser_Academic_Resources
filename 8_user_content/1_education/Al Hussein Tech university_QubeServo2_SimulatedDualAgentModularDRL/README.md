# Dual-Agent Deep Reinforcement Learning for Swing-Up and Stabilization of the Qube-Servo 2 Rotary Inverted Pendulum

## Overview
This repository contains the implementation and experiments for a **dual-agent deep reinforcement learning (DRL)** approach to control the **Quanser Qube-Servo 2 inverted pendulum**. The project is implemented in **MATLAB** and includes **Simulink (`.slx`) simulation models**, along with saved agent artifacts and demo videos.

*Credit: Eng. Iman Hindi, Industrial Engineering Department, Al Hussein Technical University (HTU), Jordan.*

---

## How the Quanser Community Can Use This
- Use as an advanced **Qube-Servo 2 simulation-based RL lab module** demonstrating modular control with two agents (e.g., swing-up and balancing).
- Build student exercises around running the provided **Simulink (`.slx`) simulation models**, then modifying rewards/termination logic and observing behavioral changes.
- Turn it into a capstone-style lab: compare “single-controller” vs **modular / staged** RL control by restructuring blocks and evaluation scripts.
- Extend toward real-world validation by porting the controller workflow to **Qube-Servo 2 hardware**, then logging and sharing performance results (stability, success rate, robustness) with the Quanser community.

---

## Experimental Setup
- **Platform modeled:** Quanser Qube-Servo 2 (rotary inverted pendulum)
- **Environment:** Simulink-based simulation (training/evaluation in simulation)
- **Artifacts:** MATLAB code and Simulink models (`.slx`) for inverted pendulum control tasks (including swing-up and balancing model files)
