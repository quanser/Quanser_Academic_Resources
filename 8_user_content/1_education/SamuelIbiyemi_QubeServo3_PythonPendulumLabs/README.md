# Pendulum Labs in Python (Quanser Qube-Servo 3)

## Overview

This project is a **Python port of the pendulum labs in Quanser's Qube-Servo 3 curriculum**. Quanser's [ABET aligned courseware][curriculum] provides application guides, lab procedures, and assessments for MATLAB and Simulink. `qube-servo3-python` follows theoriginal curriculum and adds Python implementations, so students can work through the same control concepts without MATLAB or Simulink.

---

## How the Quanser Community Can Use This

- **Teach in Python:** pair the scripts with the original lab guides for introductory modeling through advanced state feedback control.
- **Set design assignments:** ask students to estimate inertia, tune balance gains, and compare tracking and motor voltage.
- **Build course projects:** improve the swing up to balance transition or contribute missing curriculum labs, testing on the digital twin before hardware.

---

## Experimental Setup

- **Platform:** Qube-Servo 3 pendulum, physical hardware or digital twin.
- **Software and language:** Python and Quanser SDK, with NumPy, SciPy, and SymPy.
