# ROS2-Gazebo Digital Twin Framework for the Quanser QCar2

## Overview

This project presents a complete **ROS2-Gazebo digital twin framework** for the **Quanser QCar2** platform. It provides a unified software architecture that enables seamless interaction between **Gazebo simulation** and the **physical QCar2** using the same ROS2 interfaces and operator GUI. The framework includes real-time sensor visualization, ROS2 Control integration, and a sim-to-real workflow for robotics education and research.

*Credit: Tan Minh Hung Truong, PhD Candidate, Laboratoire LCIS, Université Grenoble Alpes, France.*

---

## How the Quanser Community Can Use This

- Learn and practice **ROS2-based autonomous vehicle development** without requiring immediate access to physical hardware.
- Prototype and validate robotics algorithms in Gazebo before deploying them to the real QCar2.
- Demonstrate **sim-to-real workflows** using a unified software architecture shared between simulation and the physical platform.
- Use the framework as a starting point for integrating additional sensors, navigation algorithms, perception modules, or autonomous driving applications.

---

## Teaching Applications

This framework can support laboratory sessions and project-based learning in courses such as:

- Mobile Robotics
- Autonomous Vehicles
- Robot Operating System (ROS2)
- Robot Simulation
- Robotics Software Engineering
- Mechatronics and Intelligent Systems

Students can develop and validate algorithms in simulation before testing them on the real Quanser QCar2, significantly reducing hardware setup time while improving development efficiency.

## Experimental Setup

- **Platform:** Quanser QCar2
- **Simulation:** Gazebo Classic 11
- **Operating System:** Ubuntu 22.04
- **Middleware:** ROS2 Humble
- **Control Framework:** ROS2 Control
- **Sensors Supported:**
  - RGB Camera
  - RGB-D Camera
  - LiDAR
  - IMU
  - Wheel Odometry
  - Four CSI Cameras
- **Operator Interface:** Custom real-time GUI supporting both simulation and the real QCar2
