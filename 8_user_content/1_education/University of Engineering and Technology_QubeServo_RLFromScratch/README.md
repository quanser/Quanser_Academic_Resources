# rl_qube (Quanser Qube-Servo 2)


## Overview
`rl_qube` is a collection of classic reinforcement learning algorithms implemented **from scratch** (no libraries) in **MATLAB**, with an additional **DQN implementation in C++** trained on CPU.  
This repo includes core RL building blocks (e.g., neural networks, backprop, replay buffers) written by the author and is intended to be runnable on real systems like the **Quanser Qube-Servo**, with implementations available as **Simulink (.slx)** models.

---

## How the Quanser Community Can Use This
- Turn it into a Qube-Servo RL lab where students can inspect and modify every algorithm component (no hidden libraries).
- Use the Simulink (`.slx`) models as lab scaffolding for hands-on learning and controller tuning exercises.
- Run side-by-side comparisons (DDPG vs TD3 vs SAC) as a teaching module on stability and sample efficiency.
- Extend as course projects: adjust rewards, exploration noise, or network structure and evaluate changes in Qube-Servo behavior.

---

## Experimental Setup
- **Target platform:** Quanser Qube-Servo 2
- **Additional implementation:** DQN in C++ with CPU-based training
